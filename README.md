基于K1 MUSE Pi Pro的端侧 AI 智能药盒与用药推理闭环系统
本作品面向居家老人及病房多药管理，基于进迭时空K1 MUSE Pi Pro开发的端侧AI智能药盒系统。系统采用约55×45×30cm PP板外壳，集成12个独立电控药仓（含自动弹开驱动与闭合反馈）、10英寸触控屏、摄像头和语音播报设备，围绕药品录入、方案生成、放药入仓、服药核验、数据反馈和药物咨询构建闭环。系统支持药单本地OCR识别与手动编辑，生成可编辑确认的药品条目；用户确认后，依托本地药品说明书库、药物相互作用矩阵、标准服药规则和个性化作息，采用“规则索引+端侧大模型推理+程序校验”生成安全、可解释的服药方案。放药时，本地OCR识别药盒并匹配已录入条目，智能分配仓位、自动弹仓，引导放入并实时确认关门状态。服药时，系统语音提醒，用户经本地人脸识别后弹出药仓，摄像头实时识别并核对取药数量，发现多拿、漏拿或错拿即时告警。系统记录提醒、开关仓、身份核验和异常事件，形成用药依从性数据并反馈家属或医护。用户还可通过触控屏、语音或药盒视觉识别发起药物咨询，由端侧大模型基于本地知识库生成中文解释，并支持联网语音合成自然播报，实现“本地药学知识库+端侧AI推理+多模态执行交互”的全流程智能用药闭环。`
