产品简介：本作品面向居家老人及病房多药管理，基于进迭时空K1 MUSE Pi Pro开发的端侧AI智能药盒系统。系统采用约55×45×30cm PP板外壳，集成12个独立电控药仓（含自动弹开驱动与闭合反馈）、10英寸触控屏、摄像头和语音播报设备，围绕药品录入、方案生成、放药入仓、服药核验、数据反馈和药物咨询构建闭环。系统支持药单本地OCR识别与手动编辑，生成可编辑确认的药品条目；用户确认后，依托本地药品说明书库、药物相互作用矩阵、标准服药规则和个性化作息，采用“规则索引+端侧大模型推理+程序校验”生成安全、可解释的服药方案。放药时，本地OCR识别药盒并匹配已录入条目，智能分配仓位、自动弹仓，引导放入并实时确认关门状态。服药时，系统语音提醒，用户经本地人脸识别后弹出药仓，摄像头实时识别并核对取药数量，发现多拿、漏拿或错拿即时告警。系统记录提醒、开关仓、身份核验和异常事件，形成用药依从性数据并反馈家属或医护。用户还可通过触控屏、语音或药盒视觉识别发起药物咨询，由端侧大模型基于本地知识库生成中文解释，并支持联网语音合成自然播报，实现“本地药学知识库+端侧AI推理+多模态执行交互”的全流程智能用药闭环。`

整体的搭建流程大概是这样子的：1、通过角码将上下底面和左右两面拼接牢固，形成稳定的外边缘结构 附：角码固定外边缘结构.jpg
2、将前面板通过pp胶水与外边缘框架连接
3、再利用pp胶的粘性，将12个药柜框架自下往上搭建好，注意要与前面板对齐
4、将放置k1开发板的平台对照前面板的框架用角码固定好，给触控屏预留好固定用到的角码，用铜柱固定好10英寸屏幕
附：整体框架.jpg
5、将木柜拼接好，在木柜后方钻孔用螺丝固定住电控锁配套的扣子
6、在每个柜格后方固定电控锁，底部用热熔胶固定，确保电控锁固定后，每一个木柜的前面与前面板对齐
附：电控锁安装后的效果.jpg
7、根据下图在柜子后方固定好锁控板、电源、12v转5v usb模块，用热熔胶固定
电源模块及锁控板.png
8、将imx219摄像头和ov5647摄像头插入开发板
附：摄像头排线插入位置.png
9、ov5647摄像头通过开发板平台的小圆孔固定在识别区正上方，imx219通过胶带固定在前面板预留的孔位上
附：ov5647摄像头通过开发板平台的小圆孔固定在识别区正上方.png
附：imx219通过胶带固定在前面板预留的孔位上.png
10、屏幕需要连接power usb供电（由12v转5v模块提供）hdmi接口与k1开发板hdmi接口连接、ctouch与k1开发板usb口通过数据线连接。开发板接入usb麦克风及usb扬声器。开发板引脚只需接入1、6、27、28引脚与锁控板进行连接
