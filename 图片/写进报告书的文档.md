# 报告图片素材模块：写进报告书的文档

## 1. 简要介绍

本文件夹用于集中存放最终报告需要插入的图片素材，包括整机照片、机械结构照片、锁控板原理图和 PCB 图、前端界面截图、系统框图、功能演示截图等。该文件夹本身不是算法功能块，但对报告排版和成果展示非常重要。

## 2. 建议图片清单

| 报告章节 | 建议图片 |
| --- | --- |
| 2.1 整体介绍 | 系统整体框图 |
| 2.2 硬件整体 | 整机正面、斜 45°、内部结构 |
| 2.2 机械设计 | 12 药仓、单个抽屉、电控锁安装 |
| 2.2 电路设计 | 锁控板原理图、PCB、焊接实物、K1 接线 |
| 2.3 软件系统 | 前端首页、成员管理、服药方案、药柜管理 |
| 3.3 特性成果 | 药盒识别、弹仓、关门反馈、药丸数量识别、依从性曲线 |

## 3. 图片命名建议

建议统一命名：

```text
01_整机正面.jpg
02_整机斜45度.jpg
03_12药仓内部结构.jpg
04_锁控板PCB.png
05_锁控板实物.jpg
06_前端首页.png
07_服药方案页面.png
08_药盒识别演示.png
09_药丸数量识别演示.png
```

## 4. 报告使用原则

- 每张图下方写清楚“图名 + 作用”。
- 实物照片优先，算法截图次之。
- 尽量用同一光照和背景拍摄整机图。
- 涉及性能数据的截图要保留终端输出或页面结果。
